# HostelHaven — описание пользовательских сценариев (user flow)

Документ для презентации клиенту. Описывает сценарии работы администратора в системе управления хостелами HostelHaven.

Система — веб-приложение для управления несколькими хостелами: заселение и выселение гостей, контроль оплат и долгов, SMS-напоминания, аналитика загрузки и доходов. Роли не разделены — один администратор управляет всеми хостелами.

---

## 1. Авторизация

**Входящая точка:** открытие приложения.

1. Пользователь вводит email/логин и пароль (пароль — минимум 8 символов).
2. Система проверяет учётные данные через CMS (Strapi).
3. При успехе — переход на главную страницу (Дашборд).
4. При ошибке — сообщение об ошибке, доступ повторяется.

Особенности:
- Регистрация закрыта — учётные записи создаёт администратор системы.
- Демо-доступ для презентации: `admin@hostel.com` / `admin123`.
- В шапке приложения отображается имя вошедшего пользователя; доступен выход из аккаунта.

## 2. Дашборд (Главная)

**Входящая точка:** после входа, пункт меню «Дашборд».

### 2.1. Обзор показателей
- Карточки: число хостелов, активных гостей, занятых номеров, доход (в злотых).
- При отсутствии фильтров данные по доходам/заполнению приходят с сервера (эндпоинт метрик).

### 2.2. «Неоплаченные счета» — контроль долгов
1. Сводка по гостям с просроченными или наступающими платежами: сумма долга, число платежей, статус («Ожидает», «Просрочка N дн.»).
2. Градация просрочки цветом: до 7 дней — жёлтый, 7–14 — оранжевый, более 14 — красный.
3. Действия по каждому должнику:
   - **Отправить SMS** — открывается предпросмотр сообщения «Уважаемый/ая …, напоминаем об оплате …», сумма и первый срок оплаты подставляются автоматически. После подтверждения платежам ставится отметка «SMS отправлено».
   - **Позвонить** — переход на номер телефона гостя.
   - Переход в карточку гостя по клику на имя.

### 2.3. Фильтры по периоду
Над графиками закреплена панель:
- Выбор хостела («все хостелы» / конкретный);
- Период «от–до» (по месяцам);
- Сброс фильтров;
- Глубина графиков: 3 / 6 / 12 / 24 месяца / все.

### 2.4. График «Доходы по месяцам»
- Столбцы по месяцам со статусной разбивкой: оплачено (зелёный), ожидает (жёлтый), просрочено (красный).
- При наведении — тултип с суммой за месяц.
- Сводка: доход за период, средний доход в месяц, оплачено / ожидает / просрочено.

### 2.5. График «Размещение по месяцам»
- Столбцы по месяцам (ночлеги), красная линия — динамика средней загрузки (%).
- Тултип: ночлеги, среднее число гостей, загрузка.
- Сводка: среднее число гостей в месяц, гости за период, заселения, выселения, средняя загрузка.

### 2.6. Системные предупреждения (alert'ы)
Автоматически формируются и выводятся:
- Перебронированный номер (гостей больше, чем кроватей) — критично;
- Просроченные платежи — критично, с числом гостей и суммой;
- Номера, нуждающиеся в уборке (заняты частично) — предупреждение;
- Активные гости без паспорта — предупреждение;
- Выселение сегодня с неоплаченным счётом — критично.

### 2.7. Список «Ваши хостелы»
Карточки хостелов: название, адрес, номера, загрузка %, гости, доход. Клик — переход в детальную страницу хостела.

## 3. Хостелы

### 3.1. Список хостелов

**Входящая точка:** пункт меню «Хостелы».

1. Сетка карточек всех хостелов: название, адрес, этажность, парковка, число номеров, занято/всего кроватей, гости, доход, полоса загрузки.
2. **«Добавить хостел»** — модалка:
   - название, адрес, фото (URL);
   - динамический список номеров: номер, этаж, число кроватей, тип (Economy / Standard / VIP), цена за кровать в сутки;
   - валидация: название обязательно, номер — обязательно; минимум один номер;
   - после сохранения хостел появляется в списке.

### 3.2. Страница хостела

**Входящая точка:** клик по карточке хостела.

Шапка: название, адрес, инфраструктура (этажи, кухни, парковка, души, туалеты), кнопка «Редактировать» (название и адрес). Мини-показатели: кровати (занято/всего), комнаты, жильцы, доход, число должников. Полоса заполнения.

Вкладки:

**Карта комнат** — визуальная планировка по этажам, «живое время». Цвет номера: свободен (зелёный), частично занят (жёлтый), полон (красный), VIP — фиолетовый. На карточке: фото, номер, балкон/санузел, тип, занятость кроватей (полоски), цена. Иконки заселения/выселения, если события сегодня. Фильтр по типу номера. Клик — страница комнаты.

**Расписание** — лента «заселения/выселения» на ближайшие 7/14/30 дней.
- Каждая ячейка дня: число свободных мест, полоса загрузки, события дня (заселения — зелёные, выселения — жёлтые; если у гостя неоплаченный счёт — красная рамка и иконка долга), текущий день выделен.
- Кнопка «Добавить» внутри дня, если есть свободные места → быстрое заселение с предзаполненной датой.
- Блоки рядом: «Свободные комнаты» (число свободных мест) и «Ближайшие выселения» (по дням).

**Гости** — все гости хостела (активные, забронированные, выселенные). Поиск по имени/телефону, фильтры по статусу и по оплате («Оплатили», «Не оплатили», «Должники»). Кнопка «Добавить гостя» (модалка с выбором комнаты, где есть свободные места).

**Жильцы** — только текущие активные жильцы с фильтром по оплате. По каждому — сумма оплачено и долг.

**Должники** — список гостей с долгом: имя, комната, телефон, сумма долга, кнопка звонка. Переход в карточку гостя.

**Платежи** — все платежи хостела. Фильтры по статусу (оплачено / ожидает / просрочено) и по типу (наличные / карта / перевод), поиск по гостю. Из списка можно позвонить или отправить SMS по конкретному неоплаченному платежу.

**Аналитика** — сводка за период (переключатель 3/6/12/24 мес/все):
- карточки: оплачено, ожидает, просрочено, средняя цена за ночь; общий доход, средняя загрузка, всего гостей, кроватей;
- график «Доходы по месяцам» (столбцы оплачено/ожидает/просрочено + кумулятивная линия оплат);
- график «Размещение по месяцам» (ночлеги, заселения, выселения, линия средней загрузки);
- **«Календарь загрузки»**: календарь на месяц, цвет дня по загрузке (>80%, 50–80%, <50%); клик по дню — список заселяющихся и выселяющихся; снизу — загрузка по комнатам.

## 4. Комната

**Входящая точка:** клик по номеру на «Карте комнат» или из расписания/списков.

1. Галерея фото (перелистывание, полноэкранный просмотр, клавиши ←/→/Esc), либо заглушка «нет фото».
2. Информация: номер, тип, балкон, санузел, этаж, хостел.
3. Кнопки:
   - **«Добавить гостя»** (только если есть свободные места) — модалка: имя, телефон, email, паспорт, даты заселения/выселения; автоматически считается стоимость «цена кровати × ночи»; после сохранения создаются гость и первый платёж.
   - **«Редактировать»** — номер, этаж, кровати, тип, цена.
4. Показатели: кровати (занято/всего), жильцы сейчас, цена за кровать, доход в месяц от этой комнаты; полоса заполнения (красная — полностью).
5. Раздел «Сейчас проживают» — активные гости с датами и числом оставшихся дней.
6. **«Календарь выездов»**:
   - сводка: свободно сейчас, занято сейчас, выездов на 7 дней, ближайший выезд;
   - календарь месяца: цвет дня — полностью свободен / частично / нет мест, дни с выездами выделены с инициалами выезжающих (до 3, далее «+N»);
   - клик по дню — список выезжающих в этот день и свободные места;
   - список «Следующие выезды»: имя, даты, сколько мест освободится, цвет по близости (сегодня/≤3/≤7/≤14 дн. и далее).
7. «История комнаты» — выселенные ранее гости.

## 5. Гости

### 5.1. Список «Все гости»

**Входящая точка:** пункт меню «Гости».

1. Поиск по имени или телефону; фильтры диапазона оплаченной суммы (от–до).
2. Фильтры: по статусу (активные / выселенные / забронированные) и по оплате (оплатили / не оплатили / должники).
3. Строка/карточка гостя: имя, хостел и номер, срок проживания, статус, сумма (оплачено зелёным, долг красным с минусом), кнопка звонка.
4. **«Добавить гостя»** — модалка: выбор хостела, комнаты (показываются только со свободными местами, с указанием цены), имя, телефон, email, паспорт, даты; автоматический подсчёт итоговой суммы. Создаётся гость со статусом «активный».

### 5.2. Карточка гостя

**Входящая точка:** клик по имени гостя из любого списка.

Левая колонка:
- Профиль: инициалы, имя, статус (активный / забронирован / выселен), телефон, email, паспорт, кнопка «Редактировать» (изменение данных, дат, статуса);
- Действия: **«Позвонить»** и **«Отправить SMS»** (напоминание о задолженности с предпросмотром и подтверждением);
- «Размещение»: хостел, номер, заезд, выезд.

Правая колонка:
- Показатели: оплачено, задолженность (красная, если есть), дней до выезда.
- **«Календарь проживания»** — сетка месяцев проживания от заезда до выезда, каждый месяц окрашен по статусу оплаты: оплачено (зелёный), ожидает (жёлтый), просрочено (красный, пульсация), предстоящий (серый); текущий месяц выделен рамкой «СЕЙЧАС»; на карточках — сумма месяца, отметка «SMS» если напоминание отправлено.
- **«История платежей»**: каждый платёж с суммой, типом (карта/наличные/перевод), сроком и датой оплаты, статусом; для просроченных — кнопка «Отправить SMS» по конкретному платежу; бейдж «N× просрочено» если есть долги.

## 6. Оплаты

**Входящая точка:** пункт меню «Оплаты».

1. Сводные карточки: оплачено / ожидает / просрочено (в злотых) и число SMS-напоминаний отправлено.
2. Легенда статусов и поиск по имени гостя.
3. Фильтры по статусу (оплачено / ожидает / просрочено) и по типу (наличные / карта / перевод).
4. Таблица (на мобильном — карточки): гость, номер, сумма, срок, дата оплаты, тип, статус.
5. Действия по неоплаченным платежам:
   - **SMS** — предпросмотр персонального напоминания и отправка (отметка «SMS» на платеже);
   - **Позвонить** гостю (у просроченных — кнопка всегда видна).
6. Ссылки на карточку гостя по клику.

## 7. SMS-напоминания

**Входящая точка:** пункт меню «SMS».

### 7.1. Правила отправки
Пять предустановленных правил напоминаний:
1. За 3 дня до срока (включено);
2. За 1 день до срока;
3. В день срока;
4. 1 день после просрочки;
5. 3 дня после просрочки (выключено по умолчанию).

По каждому правилу администратор может:
- включить/выключить (переключатель), удалить;
- посмотреть предпросмотр сообщения с подставленными значениями;
- **отредактировать шаблон** — textarea с лимитом 160 символов (одна SMS) и кнопками-плейсхолдерами: `{imie}` — имя, `{kwota}` — сумма, `{data}` — срок, `{hostel}` — хостел, `{pokoj}` — комната.

При выборе шаблона для конкретного платежа система подбирает правило по сроку: если просрочено ≤3 дней — «1 день после», иначе «3 дня после», для ожидающих — «за 3 дня».

### 7.2. Счётчики
Активные правила, ожидающие платежи, просрочки, отправленные SMS.

### 7.3. История SMS
Все платежи, по которым отправлено/повторно отправлено SMS: гость, комната, сумма, срок, статус оплаты, просрочка в днях. Кнопки: «Отправить» (для новых) и «Отправить повторно».

### 7.4. Отправка
Открывается предпросмотр с получателем и текстом; подтверждение → платежу ставится признак «SMS отправлено».

## 8. Настройки

**Входящая точка:** пункт меню «Настройки».

Вкладки:

**Профиль** — личные данные (имя, email, телефон, компания, NIP, фото), валюта (PLN/EUR/USD/CZK/GBP) и формат цены.

**Хостелы** — цены номеров по хостелам: аккордеон по хостелам, текущий диапазон цен по типам (Economy/Standard/VIP), ввод новой цены и сохранение по каждому типу. Сводная таблица средних цен.

**Уведомления** — переключатели каналов (email / SMS) и оповещений: долги, напоминания о выезде (за 24 часа), еженедельный и ежемесячный отчёты.

**Безопасность** — смена пароля (проверка текущего, минимум 8 символов, совпадение полей), включение двухфакторной аутентификации, управление активными сессиями (выход с устройств), «Опасная зона» — удаление аккаунта.

## Основные принципы

- **Автоматический расчёт долга**: статус платежа определяется датой — просрочен, если срок наступил, а оплата не получена. Суммы «оплачено» и «долг» считаются автоматически по платежам.
- **Единственная точка ввода гостя**: заселение создаёт гостя и платёж (первый месяц), стоимость = цена кровати × ночи. Платежи за последующие месяцы добавляются администратором.
- **SMS-сценарий**: предпросмотр всегда до отправки; после отправки платеж помечается, чтобы не дублировать напоминания. Повторную отправку нужно подтвердить явно.
- **Должники на презентации**: в демо-данных часть гостей имеет просрочки для наглядной демонстрации SMS и работы с долгами.
- **Адаптивность**: таблицы на десктопе превращаются в карточки на мобильных; навигация — сайтбар (десктоп) / выдвижное меню (мобильный).
